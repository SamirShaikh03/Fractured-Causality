# UX & POLISH

## Feel & Feedback

**Universe Switching**: Quick fade flash (0.15s) with a screen tint in the universe's color. Subtle camera shake. Smooth visual telegraph of where you are.

**Causal Changes**: Entities flash when they're affected by causal propagation. Glowing lines show connections when you activate Causal Sight. Particle ripples emanate from major events.

**Paradox Building**: The meter pulses faster as instability grows. At high levels, red vignette creeps in from screen edges. Particle glitches start flickering. Tension ramps naturally without feeling cheap.

## Controls

**Responsive**: Movement starts instantly. 0.1s input buffer for responsive feel. Diagonal movement normalized so you move at same speed in all directions.

| Keys | Action |
|------|--------|
| **WASD** / Arrows | Move |
| **SPACE** | Switch Universe |
| **TAB** | Causal Sight |
| **E** | Interact |
| **ESC** | Pause |

Keyboard feels great. Tight and immediate.

## Difficulty Ramp

**Level 1 (Easy)**: Learn movement, universe switching, basic key/door puzzles.

**Level 2 (Medium)**: Causal stones, cross-universe object behavior, multi-key challenges.

**Level 3 (Hard)**: Enemies tied to causal origins, solving puzzles through entity destruction, managing high paradox.

Each builds naturally on what you learned. No sudden spikes.

## Information Design

HUD shows what matters: **Paradox meter** (top-left, critical info), **key count**, **universe indicator**. Everything else is contextual. Clean, minimal, never cluttered.
